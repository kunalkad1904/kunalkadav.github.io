# 🚀 Personal Portfolio - Kunal Kadav

A high-performance, responsive personal portfolio website designed to showcase my work as an **AWS Certified Cloud Engineer** and **GenAI Practitioner**. 

Designed with a modern "Glassmorphism" aesthetic and a focus on speed and accessibility.

## 🛠️ Tech Stack
* **Core:** HTML5, CSS3, Vanilla JavaScript
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) (via CDN)
* **Icons:** FontAwesome
* **Fonts:** Google Fonts (Space Grotesk)
* **Animations:** Custom CSS & JS Typewriter Effect

## ✨ Features
* **⚡ Zero Dependencies:** Runs purely on the browser with no node_modules or build steps required.
* **📱 Fully Responsive:** Optimized for Mobile, Tablet, and Desktop.
* **🎨 Glassmorphism UI:** Modern dark theme with semi-transparent frosted glass cards.
* **🔍 SEO Friendly:** Semantic HTML structure for better search visibility.

## 🚀 How to Run Locally
1.  Clone the repository:
    ```bash
    git clone [https://github.com/kunalkadav/portfolio.git](https://github.com/kunalkadav/portfolio.git)
    ```
2.  Navigate to the directory:
    ```bash
    cd portfolio
    ```
3.  Open `index.html` in your browser.
